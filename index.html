Guide

Install a Shader in 4 Steps

Works on Minecraft Bedrock and Pocket Edition (Android / iOS / Windows).

Download the file

Tap the Download button on any shader page to get the .mcpack file.

Open it

Tap the downloaded file — Minecraft will open automatically and start importing.

Wait for import

You'll see an "Import completed" toast once the pack is installed.

Activate it

Go to Settings → Resource Packs → My Packs, select the shader, and tap Activate.
